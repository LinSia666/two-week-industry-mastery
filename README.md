# 兩週精通一個產業

這是一個為期兩週的產業研究練習。目標是在 14 天內建立對一個產業的整體認識，並將每天的學習、資料來源與分析成果持續記錄在 GitHub。

## 練習目標

- 理解產業的範圍、歷史與價值鏈
- 認識主要公司、產品與商業模式
- 掌握市場規模、競爭格局與發展趨勢
- 整理產業術語、重要數據與可靠資料來源
- 在第 14 天完成一份產業分析總結
